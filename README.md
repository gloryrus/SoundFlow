# SoundFlow

**Независимый Android-клиент для SoundCloud и локальной музыки.** Тёмный интерфейс, персональная музыкальная волна, плейлисты, офлайн-прослушивание и локальные аудиофайлы — без собственного сервера-посредника.

## Возможности

- Поиск музыки, любимые треки и плейлисты SoundCloud.
- Лайки, создание плейлистов и добавление в них треков.
- **Моя волна** — персональные рекомендации с автоматической подгрузкой следующих треков.
- Полный плеер и миниплеер: перемотка, переключение треков, перемешивание и повтор трека или списка.
- Воспроизведение в фоне и управление музыкой из уведомления.
- Офлайн-прослушивание с сохранением обложек.
- Автозагрузка новых треков из выбранных плейлистов и любимого, режим только Wi-Fi.
- Возобновление прерванных загрузок и повтор ошибок.
- **Своё** — локальные аудиофайлы без копирования в приложение, с сохранением позиции для каждого файла.
- Сортировка локальных файлов по дате добавления и названию, удаление записи отдельно от исходного файла.
- Эквалайзер с вертикальными регуляторами и готовыми пресетами.
- Поиск по плейлистам и офлайн-коллекции.
- Обновление списков свайпом, меню трека по удержанию и анимации интерфейса.
