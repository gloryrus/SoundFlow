# Проверки SoundFlow 1.0.0

Успешно: `assembleDebug`, `assembleDebugAndroidTest`, `assembleRelease`, `testDebugUnitTest`. **275 тестов**,0 ошибок и пропусков. Release проверен без переменных подписи, т.е. это unsigned artifact, не готовый установочный release.

Новые11 тестов SoundFlow170Test: пакет из реального generated BuildConfig, MediaStyle на паузе, отсутствие отдельной карточки после уничтожения, подгрузка без Activity, отсутствие wave-запросов в обычном плейлисте, порог prefetch, ожидание на конце, отбрасывание старого результата, пауза в ожидании, backoff сетевой ошибки,90 переключений с несколькими порциями и ограниченным окном, next_href/исключения. Некоторые из этих11 тестов проверяют несколько связанных сценариев.
Новые7 WaveCatalog170Test: disk metadata без загрузки всей Library, неизменность существующих записей, разделение аккаунтов, подтверждённый like-state, санитарная обработка remote, чтение последних300 без удаления остальных, восстановление wave checkpoint.

Изменены ожидания старых notification-тестов по новому запросу: после фактического уничтожения службы больше нет обычной reserve-card. Нормальная пауза живой службы сохраняет музыкальное уведомление и плеер. Старые проверки локальных файлов/позиций/удаления, плейлистов, офлайна и транспорта сохранены.

Все unit-сценарии — **синтетические Robolectric**, преимущественно SDK28. В wave player tests prepare/ответы источника подменены: это не проверка настоящего непрерывного звука или реального SoundCloud-каталога. Instrumentation APK только собран; не запущен. Реальный телефон/прошивка/MediaSession на Android35/Doze/LMK/расход RAM не проверены. Визуально проверена модель круговой adaptive icon; внешний вид на конкретном launcher не тестировался.

Проверены JSON задач VS Code, ресурсные XML, наличие Wrapper JAR, отсутствие старых Java package declarations. Задачи запускают те же проверенные Gradle-команды; VS Code на физическом Windows/macOS не запускался. Сборке впервые нужны интернет/JDK21/SDK35 и принятые Android SDK licenses. Release-подпись личным ключом пользователя не тестировалась.

## Ручная проверка перед публикацией
1. Установить новый пакет com.farika.soundflow рядом с прежней Flow. Проверить имя и adaptive/monochrome icon на launcher.
2. Войти в SoundCloud, проиграть волну дольше одной порции с закрытым Activity. Проверить конец очереди, сеть off/on, пустую выдачу, смену аккаунта/списка и паузу во время ожидания.
3. Проверить музыкальную карточку на паузе, блокировку экрана, гарнитуру, свайп закрытия и системное восстановление. Нельзя обещать работу после принудительной остановки/уничтожения всего процесса.
4. Повторить лайки, создание/наполнение плейлистов, офлайн-загрузки/обложки/продолжение, автозагрузки, «Своё»/SAF и позиции.
5. Открыть исходники на своём компьютере, настроить SDK/JDK, выполнить Ctrl+Shift+B. Для стабильных обновлений подготовить собственный постоянный release-ключ и резервную копию; не публиковать ключи/пароли.

Публичный transport-test.p12 — тестовый TLS fixture, не production signing key. Исходники не содержат приватного Android signing key.
