# Установка SoundFlow 1.0.0

Поверх предоставленной SoundFlow 0.17.0 устанавливается без удаления: пакет и подпись сохранены, versionCode повышен с22 до23.

Это новый пакет **com.farika.soundflow**, отдельный от «Волна Flow». Удалять старое приложение для установки не нужно. Данные старой версии автоматически не переносятся: войдите в SoundCloud заново, скачайте нужную музыку и добавьте ссылки на локальные файлы в «Своё».

Приложенный APK — тестовая debug-сборка. Для публикации собственного release выберите и сохраните личный ключ подписи; инструкции в README. APK с разными подписями нельзя обновлять поверх друг друга.

Настоящий медиаплеер остаётся на паузе без30-секундного таймера. При фактическом уничтожении службы нет отдельной обычной карточки «На паузе»; состояние хранится для восстановления. Android/прошивка может уничтожить весь процесс.

Персональная волна автоматически подгружает следующие порции в службе плеера. Нужны сеть и доступные рекомендации SoundCloud. При ошибке — повтор с задержкой. Количество порций не ограничено, но каталог не бесконечен и абсолютное отсутствие повторов не обещается.
