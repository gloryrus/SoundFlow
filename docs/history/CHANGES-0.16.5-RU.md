# SoundFlow 0.16.5 — тихие проверки

## Автопроверки только в живом процессе
- Таймер стартует при открытии основного экрана или загрузок. Первая автоматическая проверка — примерно через 15 минут; следующая — через 15 минут после завершения предыдущей. Повторное открытие экрана не создаёт ещё один таймер.
- Работает со свёрнутым интерфейсом, пока процесс остаётся в памяти и Android даёт ему выполнять код. Android может заморозить процесс или отложить выполнение: точный интервал не гарантируется.
- После уничтожения процесса таймер исчезает. Нет периодического JobScheduler, AlarmManager, отдельного foreground-service или wakelock ради автопроверок. Старое периодическое задание отменяется. Запуск фонового задания скачивания сам по себе таймер не создаёт.
- Проверяются только включённые автозагрузки текущего аккаунта с соблюдением настройки Wi-Fi. Проверка использует актуальный полный список, но не скачивает аудио сама: найденные недостающие файлы передаются отдельной очереди.
- Завершённая автозагрузка без недостающих файлов не планирует системных пробуждений ради проверки. Сетевое событие также не запускает повторную проверку завершённого списка.
- Явная кнопка «Проверить очереди», включение автозагрузки и ручная загрузка могут запрашивать проверку сразу, не дожидаясь таймера.

## Уведомления только при скачивании
- Проверка списка, подготовка очереди, проход уже сохранённых треков и ожидание следующей попытки не создают уведомление о скачивании.
- Уведомление появляется при фактической попытке сохранить недостающую аудиокопию или обложку. Счётчик показывает требующие загрузки элементы, а не все 164 уже сохранённых трека.
- После завершения или остановки передачи уведомление убирается; отдельного уведомления «Готово» нет. Результат и ошибки остаются внутри приложения.
- Анимация кнопки загрузок связана с фазой сохранения файлов, а не с проверкой метаданных. Уведомление воспроизведения не удаляется вместе с уведомлением скачивания.
- Не используется скрытый foreground-service: старый вход OfflineDownloadService только передаёт запрос в очередь и сразу завершается. Сами загрузки идут через JobScheduler с обычным уведомлением передачи.

## Незавершённые скачивания — отдельно
- Ранее начатая очередь файлов сохраняется и может продолжаться после уничтожения процесса/восстановления сети. Это продолжение скачивания, не периодическая проверка изменений плейлиста. При возобновлении используется сохранённый снимок списка; новый полный запрос нужен при явной проверке или отсутствии исходного снимка.
- Задания передачи зависят от ограничений и квот Android. Рабочая порция ограничена примерно 8 минутами, затем оставшаяся очередь может продолжиться следующей попыткой. Немедленное и непрерывное выполнение в фоне не гарантируется. Прерванный отдельный файл может скачиваться заново; готовые файлы повторно не сохраняются.
- Сохраняются задержки повторов ошибок, защита от коротких копий, локальные обложки и исключения удалённых офлайн-треков. Проверка с отсутствующей обложкой ставит её в очередь, а не считает список полностью готовым.
- Новые явные запросы не теряются при завершении более старого запроса. Отмена убирает уведомление, поздний callback не возвращает его.

## Установка и проверки
Установить поверх SoundFlow 0.16.0–0.16.4 без удаления приложения/данных. Пакет com.farika.soundflow; versionCode 18; versionName 0.16.5-quiet-checks. Сертификат сохранён: e5f7a6fe6edb98459740e2283e205405e067edddb6268147614cc25c3f10bb6f. Старая Offline Test 0.15.1 — другое приложение.

assembleDebug/testDebugUnitTest: 166 тестов, 0 ошибок, 0 пропусков. В том числе 25 новых сценариев тихих проверок: неизменённый список164, новые1/2 файла, пустой список, ошибка метаданных, обложки, backoff, исключения, передача работы из таймера в очередь, отсутствие системных заданий для завершённого списка, удаление старого periodic-job, таймер15мин без дублирования, отмена/поздние callbacks, ручной запрос без foreground-подготовки. Подпись проверена apksigner; версия/пакет — aapt.

Тесты используют Robolectric и синтетические API/Android-состояния. Физический телефон, Doze/заморозка конкретной прошивки, реальная сеть SoundCloud, серверные права и длительная фоновая загрузка не проверены. Уничтожение процесса моделируется остановкой таймера, а не аппаратным тестом LMK. Приватный ключ и пароль подписи не входят в публичные исходники.
