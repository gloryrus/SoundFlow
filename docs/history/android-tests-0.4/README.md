# Android test sources — test APK only

These classes are not packaged into the release application. Run only on a dedicated emulator/test install without real accounts or personal data. The instrumentation APK must have the same certificate as target package `com.farika.soundflow.loginfix`.

- `NativeSmoke`: version, AES-GCM/tamper rejection, URL checks, fail-closed behavior without Widevine/session, synthetic offline-original storage, Media3 play/pause/seek/background/delete, and an optional **public metadata-only** lookup of Hootie Frutti. No real DRM license is acquired.
- `ScenarioSmoke`: a test-process HTTPS handler returns **only synthetic responses**. It blocks all unexpected HTTPS and is installed before synthetic test authorization is created. Tests POST create/delete likes, request headers/body, one-shot 403 rejection, local taste feedback, bulk downloading two synthetic authorized originals with one rejected preview, ordered playlist snapshots, honest partial completion, dedup across two playlists, playing an original playlist URI via its local copy, multi-seed ranking, and real release-UI dialogs for 403 and batch confirmation. Synthetic preferences/files are cleaned up before the instrumentation result is returned.

Manifest entries for an APK with package `app.volna.test`:

```
<instrumentation android:name="com.farika.soundflow.NativeSmoke" android:targetPackage="com.farika.soundflow.loginfix"/>
<instrumentation android:name="com.farika.soundflow.ScenarioSmoke" android:targetPackage="com.farika.soundflow.loginfix"/>
```

Compile against Android platform 35, application release classes and Media3 1.5.1 dependencies. Supply `assets/test.wav` generated by `make-tone.py`. Package test classes via Android build tools and sign the separate test APK with your local application's test key. The original signing key and local test APK are intentionally not distributed.

```
adb shell am instrument -w app.volna.test/com.farika.soundflow.NativeSmoke
adb shell am instrument -w app.volna.test/com.farika.soundflow.ScenarioSmoke
```

Do not open activities in parallel with `startActivitySync`. `ScenarioSmoke` emits visual stages 7–11 while showing synthetic test data; they are not real recommendations or real-account results. Tests do not establish that SoundCloud accepts writes or offline-license requests for a real account.
