# Проверки «Волна Direct» 0.2

Дата: 23 октября 2026, UTC. Это отчёт о фактических проверках, не обещание совместимости со всеми аккаунтами и устройствами.

## Среда

- JDK 21, Android Gradle Plugin 8.7.3, Gradle 8.9.
- SDK Platform 35, Build Tools 35.0.0; minSdk 26, targetSdk 35.
- AndroidX Media3 ExoPlayer и HLS 1.5.1.
- Эмулятор AOSP Android 8.0 API 26 x86_64, 432×936 px, 180 dpi, без аппаратного ускорения.
- APK release-варианта с тестовым сертификатом. Признак application-debuggable отсутствует; apksigner подтвердил v2.
- Ни пароль, ни пользовательский токен/аккаунт SoundCloud для проверок не предоставлялись. Приватная авторизация не имитировалась.

## Подтверждено в приложении

- Подписанный APK устанавливается и запускается.
- Публичный поиск `ambient` выполняется из Android напрямую в SoundCloud, без backend разработчика.
- Загружены настоящие названия, исполнители, длительности и обложки; визуально просмотрен native-экран списка.
- Пагинация поиска: после второй страницы показано 99 уникальных записей (дубликат отфильтрован).
- Разрешён доступный поток реального публичного трека, воспроизведён HLS AAC с CDN SoundCloud.
- MediaSession подтвердила STATE_PLAYING (3), полный плеер показывал нарастающий прогресс около 14 секунд и длительность 1:44. Это не встроенный демонстрационный аудиофайл.
- Перемотка: после касания SeekBar позиция составила около 77 секунд.
- После перехода на домашний экран Android воспроизведение продолжалось (STATE_PLAYING).
- Системная медиакнопка паузы перевела плеер в STATE_PAUSED (2), позиция сохранялась.
- После повторной установки release APK публичное воспроизведение повторено; системная пауза подтвердила позицию около 8,9 секунды.
- В журнале AndroidRuntime не обнаружено FATAL EXCEPTION с Process: com.farika.soundflow в ходе этих проверок.
- Просмотрены реальные снимки guest-главной, поиска и полного плеера с настоящей обложкой. Переполнений и перекрытия элементов не обнаружено на тестовом экране.

Состояния движка и прогресс подтверждают проигрывание; качество звука на физическом телефоне/гарнитуре не оценивалось.

## Дополнительные проверки прямого веб-интерфейса

С компьютерного окружения, отдельно от Android, у SoundCloud получены реальные ответы:
- Конфигурация публичного веб-клиента из soundcloud.com.
- Публичный поиск с collection и next_href.
- Метаданные трека и related tracks.
- Публичные users/{id}/track_likes, users/{id}/playlists и users/{id}/playlist_likes; формы данных соответствуют парсеру.
- AAC HLS endpoint вернул адрес playback.media-streaming.soundcloud.cloud, оттуда получен корректный HLS-манифест версии 7.

Эти проверки НЕ заменяют авторизацию и проверку приватной библиотеки пользователя.

## Найденные и исправленные проблемы

- Один устаревший вариант `audio/mpegurl` возвращал 404, хотя AAC-варианты того же трека были доступны. Добавлен выбор поддерживаемого MP3/AAC и fallback между легитимными вариантами при 404/410/415. Для 401/403 нет обхода доступа.
- SoundCloud использует новый CDN playback.media-streaming.soundcloud.cloud, а не только sndcdn.com. Точный hostname добавлен в allowlist после проверки ответа SoundCloud; чужой прокси не использовался.
- Системный MediaPlayer Android 8 не разобрал современный поток (ошибка -1007). Он заменён на Media3 ExoPlayer с явным HLS MIME-type. Успешные проверки воспроизведения выше относятся к Media3, а не к прежнему ошибочному движку.
- Исправлены пустые/NULL next_href, защита от устаревших ответов при смене экрана, обработка паузы во время подготовки, завершение входа после отмены и размеры toolbar входа в dp.
- Последняя запись каталога минимизирует сохраняемые remote-метаданные: временный track_authorization и transcoding URL не сохраняются в библиотеку; поток запрашивается заново.

## НЕ проверено end-to-end

- Вход с реальным аккаунтом, MFA, CAPTCHA, конкретные провайдеры социальной авторизации и длительность жизни веб-сессии.
- Приватные лайки/плейлисты пользователя, изменение лайка, создание и редактирование своего плейлиста. Код есть, успех в вашем аккаунте не подтверждён.
- Загрузка оригинала от автора и офлайн-воспроизведение скачанного файла в этой версии. Условия downloadable и отсутствие stream-ripping проверены по коду, но реальная авторизованная загрузка не выполнена.
- Исчерпывающая матрица регионов, всех треков/форматов, платного контента и всех политик SoundCloud.
- Физические устройства, Android 13–16, Android Auto, OEM-ограничения фоновой работы, уведомления Android 13+ и отдельный lock-screen UI-тест.
- Bluetooth-гарнитуры, звонки, TalkBack, большой шрифт, планшеты, большие библиотеки, поведение после process death, нестабильная сеть и многочасовая сессия.
- Оригинальный алгоритм рекомендаций SoundCloud: он не воспроизведён, используется related-подбор.

Нельзя считать этот APK полной, официально поддерживаемой заменой SoundCloud или гарантировать все исходные требования. Это экспериментальная сборка с подтверждёнными публичным поиском и прямым воспроизведением; следующая необходимая проверка — вход на вашем телефоне.
