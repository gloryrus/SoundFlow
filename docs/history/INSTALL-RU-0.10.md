# SoundFlow 0.10.0 — установка

Установите APK поверх Lab0.5–0.9, не удаляя приложение и не очищая данные. Пакет и подпись прежние.

1. Настройки → Локальный обход DPI → Дробление TLS ClientHello. По умолчанию выключено. Внешний сервер и системный VPN не нужны; локальный транспорт находится внутри приложения. Применяется к новым нативным соединениям. Если связь ухудшается, выключите режим и перезапустите трек.
2. Эта функция экспериментальная: работа на вашем провайдере не проверена. Не помогает против IP/DNS-блокировки, не охватывает вход через сайт/WebView, не меняет регион аккаунта или права сервиса. SNI и сертификаты не подменяются; REALITY не используется.
3. Настройки → Музыка в фоне: продолжение при системном перезапуске плеера. Активная очередь/позиция сохраняются. После смерти процесса экраны открываются заново, но Волна, музыка, плейлисты, аккаунт и загрузки не удаляются. Само открытие приложения не включает звук.
4. Полностью уничтоженный процесс не может продолжать выдавать звук: возможна пауза до разрешённого Android перезапуска. Принудительная остановка и решения энергосбережения не обходятся. Пауза, звонок и явная остановка не запускают воспроизведение сами.

Лайки HTTP403 и треки NO_OFFLINE_SOURCE в этой версии НЕ объявлены исправленными. Для записи через официальный API нужна подходящая OAuth-интеграция зарегистрированного приложения; для офлайна — разрешённый источник/лицензия. Никакой сетевой переключатель не выдаёт эти права. Обход DRM/подписки/запрета автора не добавлен.
