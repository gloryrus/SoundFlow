# SoundFlow 0.16.2 — запуск очередей

## Установка
Установить поверх Flow 0.16.0/0.16.1, без удаления приложения и очистки данных. Пакет com.farika.soundflow; versionCode 15. Подпись совпадает с предыдущими Flow: e5f7a6fe6edb98459740e2283e205405e067edddb6268147614cc25c3f10bb6f. Старую Offline Test 0.15.1 этот APK не обновляет.

После установки открыть «Загрузки» и нажать «Проверить очереди». Переустанавливать с удалением данных или отключать и заново включать автозагрузку не требуется.

## Причина и исправление
Раньше переключатель создавал пустой план без треков, а получение списка зависело от отложенного JobScheduler. Отображённые в медиатеке 165 треков не означали, что очередь получила эти же 165 записей. Поэтому могла оставаться карточка «0 из 0» без ошибок.

Теперь:
- при включении авто полный сохранённый список медиатеки передаётся в базу очереди сразу; показанный и закэшированный список из 165 треков создаёт очередь из 165, не ограничивается первой сотней;
- из открытого экрана запуск выполняется через foreground service, без ожидания фонового задания; используется уведомление Android;
- открытие «Загрузок» и «Проверить очереди» восстанавливают старые пустые автопланы из кэша и запускают обработку при доступной разрешённой сети;
- дублирующиеся запросы одного списка в foreground service объединяются; после отмены не отправляется работа в уже остановленный executor;
- неизвестный список отличается от подтверждённого пустого: «Список ещё не получен» вместо вводящего в заблуждение «0 из 0»;
- пустые неизвестные автопланы получают отложенный повтор, а подтверждённо пустые не запускают быстрый повтор бесконечно (периодическая автопроверка остаётся);
- при отсутствии сети или при Wi-Fi-only и мобильном подключении выводится причина ожидания, очередь сохраняется;
- под VPN разрешается Wi-Fi-only, только если Android подтверждает подключённый Wi-Fi; мобильная сеть, в том числе безлимитная, не считается Wi-Fi. Если Android скрывает тип сети под VPN, скачивание ожидает подтверждённого Wi-Fi;
- автоматический foreground-процесс также прекращает сетевую работу при смене на запрещённую сеть; прогресс и повтор сохраняются;
- миграция БД v2 → v3 сохраняет существующие записи и готовые состояния.

## Авторизация / alphabet
В исходниках не найдена статическая строка alphabet. На предоставленных скриншотах этого окна нет, источник не установлен. Авторизация в этом обновлении не менялась: неизвестные системные/сайтовые диалоги и подтверждение подключения аккаунта не скрываются вслепую. Для отдельного исправления нужен скриншот самого всплывающего сообщения.

## Проверки и ограничения
assembleDebug и testDebugUnitTest успешны: 86 Robolectric-тестов, 0 ошибок, включая 15 новых сценариев QueueStartupTest. Проверены 165 записей кэша → очередь, восстановление старого пустого плана, миграция БД, сохранение READY, изоляция аккаунта, старт foreground service с правильными параметрами, обновление неизвестного списка, Wi-Fi/VPN/мобильная сеть.

Подпись APK проверена apksigner, package/version — aapt. Это автоматические проверки с синтетическими API/сетевыми состояниями; загрузка с реального аккаунта на физическом телефоне не проверена. Доступность каждого трека зависит от SoundCloud. Android может откладывать фоновые задания; принудительная остановка приложения пользователем блокирует их до следующего открытия. Гарантировать работу после force-stop невозможно.

Предыдущие функции 0.16.0/0.16.1 сохранены. Ключ и пароль подписи не входят в публичные исходники.
