# SoundFlow 0.9.0 — установка

Установите APK поверх текущей Lab0.5–0.8, не удаляя приложение и не очищая данные. Подпись и пакет прежние.

- Анимации: настройки приложения → Интерфейс → Анимации. Системное отключение анимаций имеет приоритет.
- Для старых технических отказов откройте Загрузки → Повторить ошибки: иначе сохранённый срок следующей попытки ещё может действовать. Готовые файлы не скачиваются повторно.
- Маршрут лайков изменён на документированный API, но успешная запись на вашем реальном аккаунте здесь не проверена. При403 приложение не подменяет серверный успех локальным. Права записи требуют подходящей авторизации; повторный вход может не помочь. Информация о доступе открывается прямо в диалоге.
- NO_OFFLINE_SOURCE означает отсутствие разрешённого оригинала/совместимого источника офлайн-лицензии. Это не ошибка Wi-Fi и не устраняется копированием запрещённого потока. Такие треки не обещаны к скачиванию.
- Очередь/позиция, возобновление при возврате аудиофокуса, эквалайзер и состояние «Для вас» из0.8 сохранены.

Эта сборка не содержит чужих ключей SoundCloud и не даёт прав подписки. Реальный403 на вашем аккаунте и выдача лицензии для конкретного трека остаются внешними условиями, не подтверждёнными синтетическими тестами.
