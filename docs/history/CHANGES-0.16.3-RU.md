Сертификат совпадает с предыдущими Flow: e5f7a6fe6edb98459740e2283e205405e067edddb6268147614cc25c3f10bb6f. Старая Offline Test 0.15.1 имеет другой пакет/сертификат и этим APK не обновляется.

## Поиск
- Поле поиска добавлено в Любимое, внутрь плейлиста и в Офлайн. Фильтрация по названию и исполнителю, без учёта регистра; е/ё равнозначны. Очистка поля восстанавливает список, исходные записи не удаляются.
- Поиск внутри уже открытого списка локальный, не отправляет запрос SoundCloud на каждое нажатие клавиши. При завершении первоначальной загрузки текущий фильтр применяется к полному результату.
- В корневом разделе Плейлисты ввод запроса включает поиск треков сразу по своим и лайкнутым плейлистам. Коллекции загружаются со всех страниц, повторы плейлистов/треков удаляются. Индивидуальное содержимое берётся из сохранённого снимка, а отсутствующий снимок загружается напрямую с SoundCloud и сохраняется.
- Без интернета поиск по плейлистам ограничен сохранёнными снимками. Поиск в Офлайне не требует подключения. Первый поиск по ранее не открывавшимся плейлистам может занять время. Последующие запросы используют кэш; он обновляется при обычном открытии/синхронизации списка. Это не live-поиск по каждой новой правке SoundCloud.
- При новом запросе/смене экрана устаревший результат не заменяет актуальный. При ошибке полного обхода результат не выдаётся за полный.

## Долгое нажатие / удаление офлайна
- Меню определяет наличие локальной копии по source ID, а не по cloud/local URI выбранной строки. В Любимом и плейлистах для уже скачанного трека отображается «Удалить из офлайна», для остальных — «Сохранить офлайн».
- Удаляется только локальная копия. Лайк и состав плейлиста SoundCloud не изменяются. Текущий трек останавливается, если удаляется именно его копия; другой играющий трек не останавливается.
- Ручное удаление запоминается отдельно для аккаунта и источника: автозагрузка не возвращает удалённую копию. Новое явное «Сохранить офлайн» снимает исключение.
- Во всех планах состояние источника меняется на REMOVED. Защита в транзакции сохранения не позволяет параллельной загрузке вернуть удалённый файл.

## Превью / безопасная замена
- Сохраняется прежний запрет на явно отмеченное API превью. Дополнительно сравниваются длительность потока и ожидаемая полная длительность.
- Для clear progressive и оригинальных файлов длительность читается Android MediaMetadataRetriever из локального файла/кэша, без сети. Для clear HLS проверяется длительность готового media playlist и полностью закэшированные ресурсы. Нулевой/непроверяемый результат не помечается готовой полной копией.
- Явно короткая копия: разница больше 5 секунд и длительность менее 90% ожидаемой. Это отличает превью от небольшого расхождения метаданных. Трек, который сам по себе длится 30 секунд, не считается превью только из-за длины.
- Старые копии с признаком превью/короткой известной длительностью получают устойчивый план восстановления. Если старые метаданные ошибочно заявляли полную длину, короткая фактическая длительность обнаруживается при подготовке офлайн-воспроизведения и ставит восстановление в очередь.
- Старая копия не удаляется перед скачиванием новой. Сначала полная копия проходит проверки и сохраняется, затем старые записи заменяются. При сбое остаётся прежняя копия. Старый offline URI перенаправляется на замену, чтобы сохранённая очередь не ломалась. Среди копий одного источника показывается одна, более полная.
- Если SoundCloud пока выдаёт только превью, полную версию невозможно создать из этого фрагмента. Сохраняется ошибка PREVIEW_ONLY с последующими проверками (обычная задержка для такого отказа около 6 часов). Фоновое восстановление соблюдает настройку Wi-Fi и ограничения Android. DRM остаётся в стандартном лицензированном пути, обхода защиты нет.

## Фоновый плеер и память
- Воспроизведение и очередь принадлежат PlaybackService, а не Activity. Удаление задачи интерфейса из недавних не останавливает активный плеер; foreground media notification остаётся.
- Wake mode плеера — NETWORK: Media3 управляет CPU/Wi-Fi lock во время воспроизведения. Добавлены обычные Wi-Fi-разрешения Android.
- При явной паузе/окончании/ошибке без ожидаемого возобновления сервис получает 30 секунд на быстрый возврат; затем сохраняет позицию/очередь, освобождает ExoPlayer, офлайн-кэш, эквалайзер, аудиофокус, MediaSession и уведомление, вызывает stopSelf. При удалении задачи в paused-состоянии освобождение сразу.
- Временная потеря аудиофокуса (например, звонок) не приравнивается к ручному выключению: намерение продолжить сохраняется.
- Во время активного запуска возвращается START_STICKY. Стабильная очередь сохраняется при новом процессе; Application больше не стирает её при старте. Восстановление системой ограничено RestartPolicy; обычный запуск UI сам по себе не включает музыку.
- При скрытии UI закрывается окно плеера и очищается кэш изображений; неиспользуемый браузер операций аккаунта закрывается. Активная операция аккаунта не обрывается только из-за onStop. При memory trim освобождаются drawables интерфейса. При возврате обложки запрашиваются заново, включая локальные.
- Это не отдельный Android-процесс интерфейса и не принудительное убийство приложения. Android самостоятельно уничтожает Activity/процесс по необходимости. Активная музыка должна сохранять сервис; отсутствие музыки больше не удерживает бессрочно именно сервис воспроизведения. Активные офлайн-загрузки работают отдельно и могут требовать своё foreground-уведомление.
- Force-stop пользователем и жёсткие ограничения батареи производителя могут остановить любой сервис; непрерывная работа в этих условиях не гарантируется.

## Оформление
- Удалён текст «SoundFlow» из верхнего левого угла; иконка волны сохранена.
- Все WaveMark используют общий монотонный WaveClock вместо собственного счётчика кадров. Волна в шапке и в блоке «Моя волна» имеют общую фазу. Анимация по-прежнему учитывает воспроизведение, видимость и настройку уменьшения движения.
