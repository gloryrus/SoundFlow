# Volna 0.15.1: прямой офлайн-кэш

## Исправление
В OfflineStore удалён локальный отказ NO_OFFLINE_SOURCE для полного незашифрованного потока. Флаг downloadable относится к скачиванию исходного оригинала: код больше не использует его как единственный способ сохранения открытого потока. Это техническое различие, не утверждение о предоставлении SoundCloud права на постоянное копирование: соблюдайте условия сервиса и права на контент.

- Разрешённые оригиналы сохраняются прежним способом.
- Полные clear HLS/progressive варианты, реально выданные SoundCloud текущей сессии, сохраняются в приватный кэш приложения. Никаких сторонних серверов.
- Для HLS выбирается отдельный аудиоплейлист, проверяются ENDLIST, длительность, адреса и отсутствие объявленного шифрования; загружаются манифест, init-сегменты и аудиосегменты.
- Повторный проход по кэшу без сетевого источника должен завершиться до ready=true. При открытии готового кэша сеть отсутствует в DataSource.Factory.
- clear-копии открываются без Widevine. Отдельная существующая ветка DRM с настоящей системной лицензией сохранена. Ключи не извлекаются; URL защищённого варианта не переписывается в открытый.
- При выборе формата полный clear-вариант приоритетнее DRM и для офлайна. Превью не превращаются в полный трек.
- Исходный отказ не заменён фиктивным успехом: отсутствующие сегменты, неполный/живой HLS, шифрование и недоступные ресурсы приводят к ошибке.
- При прерывании clear-загрузка начинается заново; межзапусковая докачка HLS не реализована. Докачка оригиналов не изменена.
- Кэш не экспортируется как MP3: HLS остаётся HLS в Media3 SimpleCache. Записи привязаны к аккаунту; смена аккаунта/очистка данных ограничивает доступ. Содержимое кэша не заявляется полностью зашифрованным: манифесты и индекс могут содержать подписанные адреса в закрытом каталоге приложения.

## Конкретный трек со скриншота
Публичная анонимная проверка SoundCloud для id 2413615341 «Так Манят Облака (Bass Boosted)» вернула downloadable=false, streamable=true, policy=MONETIZE и полные HLS-варианты snipped=false. Полученный HLS имел ENDLIST, 15 сегментов, суммарно 140.506842 сек., без EXT-X-KEY. Подписанные ссылки, токены и сами сегменты не включены в отчёт. Это проверка с сети сборочной машины, а не доказательство доступности с телефона/аккаунта пользователя.

## Проверки
- assembleDebug: успешно, подпись APK проверена apksigner.
- 12 новых Robolectric-тестов: clear HLS, progressive, master, повторное открытие записи без сети/DRM, промах кэша без сети, превью, DRM, AES, live/короткий HLS, посторонний сегмент, отсутствующий сегмент, отмена (некоторые сценарии объединены в одном тесте).
- 16 прежних Robolectric-тестов: успешно (9 SwipeDispatch + 7 WarmWriter).
- tests/run-unit.sh: успешно, 219 Java-проверок и 56 JS-проверок.
- Синтетические сегменты проверяют транспорт/кэш, не декодирование аудио. Физическое Android-устройство/эмулятор и реальное офлайн-воспроизведение на телефоне не проверялись. Нет гарантии сохранения всех треков или выдачи DRM-лицензий.

## Установка тестовой версии
APK называется Volna-0.15.1-direct-offline-test.apk. Пакет com.farika.soundflow.offlinefix, имя «Волна Offline Test», debug-подпись. Он устанавливается рядом со старой Volna, а не обновляет её. Старую версию НЕ удаляйте. Данные, сессия и кэш старой версии автоматически в тестовую не переносятся: войдите в свой аккаунт заново.

1. Установите APK и откройте «Волна Offline Test».
2. Войдите в SoundCloud; откройте проблемный трек или «Любимое» и запустите загрузку.
3. Для ранее записанного отказа используйте «Продолжить / повторить ошибки» или «Повторить отдельный трек».
4. Дождитесь завершения; включите авиарежим, отключите Wi-Fi и воспроизведите сохранённый трек с перемоткой ближе к концу. Повторите после полного закрытия приложения.
5. При сбое сохраните новый код из «Причины отказов». Пароли, cookies и токены не присылайте.

## Сборка и обновление основной установки
Нужны JDK21, Android SDK platform35/build-tools35.0.0 и Gradle wrapper.

```bash
./gradlew assembleDebug testDebugUnitTest
bash tests/run-unit.sh
```

Для APK, который обновит прежнюю установку без удаления данных, верните СВОЙ прежний ключ и config в signing-private/ и запустите ./build-apk.sh. В исходном ZIP ключа нет; прежняя подпись не может быть восстановлена из исходников или хеша сертификата. Release без ключа не получает debug-подпись. Чужие ключи/сертификаты не подставлены. Существующий package основной release-ветки сохранён; test-суффикс задан только debug-сборке.
