# Проверки 0.3.0-native-drm

Дата: 2026-10-23. Реальный аккаунт пользователя не использовался.

## Выполнено

- Release APK собран AGP 8.7.3 / Gradle 8.9 / JDK 21 / Android SDK 35. Release vital lint и проверка дублирующихся классов прошли.
- APK Signature Scheme v2 проверен `apksigner`. SHA-256 сертификата совпадает с 0.2.1-loginfix: `56126d63328d881b2da3d228f83d7065f174d5648ec1acd122173fc99c0e0036`.
- Установка `adb install -r` поверх предыдущего applicationId успешна, без удаления данных.
- `AuthCaptureTest`: 23 проверки нормализации авторизации/доменов; только синтетические строки, без сети.
- `StreamPolicyTest`: 20 проверок допустимых протоколов/MIME, выбора CTR, исключения CBC, предпочтения полного потока перед превью, проверки формата токена; без сети.
- Отдельный instrumentation APK на AOSP Android 8.0 / API 26 (432×936): 13 проверок версии, шифрования AES-GCM и отказа при изменении ciphertext, доменов, путей офлайн-хранилища, отказа DRM без CDM, отказа загрузки без сессии, открытия/удаления синтетической локальной записи, нативного проигрывания синтетического WAV, паузы/перемотки и продолжения в фоне.
- Публичный resolver для `sonyan-music/hootie-frutti` вернул метаданные полного HLS Widevine-потока и авторизацию лицензии. Значения токена и подписанных URL в отчёт не выводились. **Это не тест получения лицензии или воспроизведения защищённого аудио.**
- Визуальная проверка главного экрана, офлайн-раздела, справки и лицензий на эмуляторе; внешний вид в духе предыдущей «Волны» сохранён.

Исходники JVM-тестов и instrumentation-теста — в `tests/`. Тестовый APK и приватный ключ подписи в дистрибутив исходников не включены.

## Не проверено / не гарантируется

- На эмуляторе **нет Widevine**. Успешное получение streaming/offline-лицензии, provisioning, воспроизведение защищённых AAC/CENC и восстановление лицензии в авиарежиме должны быть проверены на настоящем устройстве с системным Widevine.
- Для отказа сервера в выдаче лицензии не выполнялся живой account-based end-to-end тест; fail-closed порядок сохранения проверен по коду и отказам без сессии/CDM. Не выдаём это за проверенную выдачу/отказ реальной лицензии.
- Вход реального пользователя, синхронизация его лайков и плейлистов, изменения в аккаунте, разрешённая оригинальная загрузка с реального аккаунта — не проверены в этой среде. Сохранён существующий механизм 0.2.1, но это не гарантия его дальнейшей работы.
- Выдача офлайн-лицензии обычному аккаунту, длительность её действия и доступ к каталогу определяются SoundCloud; успешный потоковый доступ не означает разрешение постоянного офлайна.
- Нет подтверждения доступности всех регионов, подписочных треков, отсутствия рекламы сервиса или всех функций оригинального SoundCloud.
- Android 9–15/16, разные OEM, Bluetooth, гарнитуры, отзыв лицензий, нехватка места/потеря питания и многочасовые очереди не тестировались на физических устройствах.

## Проверка пользователем

1. Обновить 0.2.1 без удаления, убедиться, что аккаунт подключён.
2. Открыть Hootie Frutti, проверить полную длительность и воспроизведение дальше 30 секунд. Если ошибка — прислать точный текст/код, версию Android и модель устройства, **не cookies/токены/пароль**.
3. Проверить лайк: изменить в приложении, затем сверить с аккаунтом SoundCloud.
4. Долгое нажатие → «Сохранить офлайн». Только явное подтверждение и запись в офлайн-разделе считаются успешным сохранением.
5. Полностью отключить сеть и запустить офлайн-запись, перемотать в середину и ближе к концу.
6. Если лицензия не выдана, истекла или устройство не поддерживается — клиент должен сообщить об этом. Замена источника или обход отказа не выполняются.
