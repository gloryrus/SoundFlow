# SoundFlow 0.16.1 — списки и автозагрузка

## Установка
Установить поверх «SoundFlow» 0.16.0, НЕ удаляя приложение и НЕ очищая данные. applicationId сохранён: com.farika.soundflow; versionCode повышен с 13 до 14. Сертификат обоих APK одинаков, проверено apksigner:

e5f7a6fe6edb98459740e2283e205405e067edddb6268147614cc25c3f10bb6f

Вход, готовая музыка и очереди Flow остаются в том же каталоге данных. Это совместимое обновление именно Flow 0.16.0, а не старой «Волна Offline Test» 0.15.1 с другой подписью/пакетом.

## Исправления
- Переключатель «Автозагрузка» расположен непосредственно над треками в «Любимом» и внутри каждого открытого плейлиста. Он относится только к текущему списку и отражает уже сохранённую настройку.
- Включение запускает обычное планирование текущих и новых треков. Выключение сохраняет диалог «Оставить треки / Удалить треки / Отмена». При отмене переключатель остаётся включённым.
- Из экрана «Загрузки» убраны включение/выключение авто и добавление списка. Там остаются состояние очередей, ошибки и продолжение/повтор. Сведения о включённой автозагрузке — обычный текст, не настройка.
- «SoundFlow» в шапке выровнена по вертикальному центру соседней иконки, без прежнего прилипания текста к верхней границе. Сохранено положение слева сверху.
- В интерфейсе «Любимое» исправлена реальная недоработка: раньше выполнялся только первый запрос likes(...), поэтому отображались первые 100 треков. Теперь LibraryPager последовательно запрашивает все страницы до отсутствия next_href.
- Общий загрузчик применяется и к коллекциям своих/лайкнутых плейлистов, удаляет повторы и отслеживает циклические курсоры. Локального ограничения 100 или 1000 элементов нет. Размер страницы API (например, 100) НЕ является размером итогового списка.
- В медиатеке кнопка «Загрузить ещё» вообще не добавляется в дерево View. Для поиска пагинация сохраняется. Содержимое отдельного плейлиста по-прежнему запрашивается целиком через playlistTracks.
- Полное «Любимое» после успешной загрузки сохраняется в кэш списка. При ошибке второй страницы первая сотня не возвращается как успешно полученный полный результат. Если доступен старый кэш, UI может показать его с явной пометкой «Сохранённый список»; это не утверждение полноты свежего запроса.
- Удалено старое ограничение 1000 в диалоге выбора плейлиста для добавления трека.

## Проверки
Сборка assembleDebug и подпись APK проверены. **71 Robolectric-тест, 0 ошибок**: 56 предыдущих, 8 новых тестов пагинации, 7 тестов экранов/переключателей.

Новые сценарии:
- 250 лайкнутых треков (100+100+50), 250 плейлистов, 1300 плейлистов без локального лимита;
- дедупликация, цикл страниц, ошибка второй страницы, отмена;
- настоящий экран «Любимое» на 164 трека, экран плейлиста на 250 треков, коллекция 123 плейлистов;
- видимый переключатель внутри нужного списка и отсутствие «Загрузить ещё» в медиатеке;
- включение авто только выбранного плейлиста;
- отмена диалога не выключает авто, подтверждение выключает;
- отсутствие контролов включения авто/добавления списка на экране загрузок;
- вертикальное выравнивание бренда в Android View.

Проверки используют синтетические ответы API и Robolectric. Физический телефон/эмулятор, реальное количество плейлистов аккаунта и визуальное выравнивание на конкретной модели не проверены. Полная загрузка может занимать время при большой коллекции и зависит от ответов SoundCloud. При сетевой ошибке полный результат не выдумывается.

Предыдущие ограничения фонового планирования Android и новые функции 0.16.0 не менялись: см. docs/CHANGES-0.16-RU.md. Ключи и пароли не включены в исходники и не передавались в этом обновлении.
