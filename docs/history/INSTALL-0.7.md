# SoundFlow0.7 — установка

Установите APK поверх Lab0.6/0.5, не удаляя приложение. Подпись та же. Отдельная0.4 не обновляется этим APK.

## Автозагрузка
- В Любимом, плейлисте или карточке в «Загрузки» нажмите **Автозагрузка**. Это одна настройка для текущих треков и новых добавлений. Нажмите повторно, чтобы выключить. Скачанные файлы не удаляются.
- Общая настройка сети: **шестерёнка вверху → Только Wi-Fi / безлимитная сеть**. При выключении разрешён мобильный трафик. Автозагрузка соблюдает выбранную сеть, Android может отложить запуск.
- Отдельная кнопка «Очередь» и диалог «Скачать всё + сохранять новые» удалены. Раздел «Загрузки» показывает прогресс и причины отказов.
- «Повторить ошибки» — явная ручная повторная попытка. Готовые файлы повторно не скачиваются. Существующие планы/копии0.6 остаются на месте.

## Эквалайзер
Выберите трек → разверните плеер нажатием на название в мини-плеере → **Эквалайзер**. Пять полос±12дБ, включение/выключение и сброс. Настройки запоминаются для следующих треков. Обработка программная, только внутри этого плеера. При повышении полос добавляется запас по громкости от перегруза. Сначала запустите воспроизведение, чтобы подготовился PCM-аудиотракт.

##403 и загрузки
Исправлена возможная подмена client_id после обновления общей веб-конфигурации. Уже потерянную привязку старого входа восстановить автоматически нельзя. Один новый вход сохраняет проверенную пару, но не гарантирует, что SoundCloud разрешит запись. Если отказ остаётся, пришлите кодACCOUNT_LIKE/CREATE/ADD и этапREAD_ACCOUNT/WRITE. Пароли, токены и cookie не отправляйте.

Не утверждается, что реальные лайки/плейлисты теперь приняты сервером: это надо проверить на аккаунте. Успех не подменяется локальной отметкой.401/403 не удаляют сессию, плейлисты или файлы.

Старое ORIGINAL_DISABLED ошибочно звучало как отказ в лицензии, хотя лицензия в той ветке не запрашивалась. Теперь отдельная причина NO_OFFLINE_SOURCE означает отсутствие разрешённого оригинала/поддерживаемого лицензированного потока. Это не исправляется настройкой Wi-Fi. Нужны права, реально предоставленные сервисом; все треки скачать не обещается.

Личный архив ключа Lab0.5 подходит для дальнейших обновлений. В публичных исходниках ключа нет; не публикуйте личную резервную копию.
