# Волна Direct 0.3.0 — native DRM (экспериментальная)

Android 8.0+, Java, AndroidX Media3 1.5.1. Независимый неофициальный клиент SoundCloud.
**Не обещает весь каталог, обход гео/подписки или полную копию официального приложения.**

## Что изменено в этой версии

- Вместо отбрасывания всех защищённых потоков выбирается выданный SoundCloud `ctr-encrypted-hls` с AAC/MP4 или HLS MIME.
- Воспроизведение через ExoPlayer и системный `FrameworkMediaDrm` Widevine. WebView/браузер не используется для проигрывания.
- `licenseAuthToken` берётся из текущего ответа SoundCloud и применяется только к обычному лицензионному запросу. Не хранится в библиотеке и не печатается в диагностике. Ключами распоряжается системный CDM Android.
- Офлайн: разрешённый автором оригинал либо зашифрованный HLS-кэш, **только после успешного получения постоянной лицензии**. Остаток сроков лицензии и воспроизведения должен быть больше 60 секунд. Затем проверяется полнота кэша без сети и только после этого создаётся готовая запись.
- Офлайн-воспроизведение защищённой записи не обращается к сети. Истёкшая лицензия, неполный кэш и необходимость повторного provisioning приводят к отказу, а не к незаметному сетевому воспроизведению.
- Фоновая очередь загрузок, уведомление, отмена. Незавершённая запись не появляется в офлайн-библиотеке.
- Лайки у сохранённых копий с идентификатором SoundCloud теперь тоже отправляются в аккаунт; интерфейс меняется только после успешного ответа API.
- Превью обозначается явно и не сохраняется как полный трек.

Из ранее реализованного сохранены поиск с пагинацией, лайки/плейлисты аккаунта, создание приватного плейлиста и добавление трека, простые похожие треки, очередь, пауза, перемотка, фон, системное уведомление и медиакнопки. **Операции аккаунта не проверены на вашем реальном аккаунте.** Рекомендации — related tracks, не официальный алгоритм SoundCloud.

## Установка обновления

APK имеет тот же applicationId `com.farika.soundflow.loginfix`, тот же тестовый сертификат, versionCode 4. Его можно установить **поверх 0.2.1-loginfix**; удаление приложения не требуется. Android должен подтвердить совместимость подписи. Не удаляйте старую версию ради обновления: это удалит сессию и локальные данные.

Если Android сообщает о несовпадении подписей — остановитесь и сохраните старое приложение; не удаляйте его автоматически. Эта тестовая подпись не предназначена для публичного production-релиза.

1. Установить APK поверх предыдущего.
2. Открыть уже подключённый аккаунт (если сессия ещё действительна).
3. Проверить Hootie Frutti и другие проблемные треки. В плеере должен появиться статус Widevine либо понятная ошибка лицензии/устройства, а не «нет MP3/AAC».
4. Долгое нажатие на трек → **Сохранить офлайн**. Дождаться подтверждения в уведомлении и записи в «Медиатека → Офлайн».
5. Отключить сеть и запустить именно офлайн-запись. Если сервер не выдал offline-лицензию, запись не будет создана — это не исправляется копированием потока.

## Прямая архитектура

```
Android → soundcloud.com                     публичная веб-конфигурация
Android → api-v2.soundcloud.com              каталог / аккаунт
Android → SoundCloud CDN                    аудио / обложки
Android MediaDrm → license.media-streaming.soundcloud.cloud
                 /playback/widevine          потоковая лицензия
                 /persistable/widevine       офлайн-лицензия, если выдаётся
Android MediaDrm → доверенный Google endpoint provisioning (если нужен CDM)
Android WebView → официальный сайт           только вход
```

Нет сервера разработчика, scnative.space, Spotify/YouTube, извлечённых DRM-ключей, чужих device-сертификатов или расшифровки на сервере. Предлагаемые сервером FairPlay/CBC-варианты не превращаются искусственно в Widevine.

Вход оставлен из работающей версии 0.2.1: официальная страница в Android System WebView, проверка обнаруженной сессии через `/me`, подключение лишь после подтверждения. Это **не зарегистрированный OAuth-клиент**. Неофициальный веб-интерфейс может измениться. Отдельный внешний браузер не передаёт приложению свою сессию сам по себе. Пароль не запрашивается в чате и не извлекается из формы. Вход через сторонние провайдеры может не поддерживаться.

Сессия и дескриптор офлайн-записи зашифрованы AES-GCM ключами AndroidKeyStore. Защищённые сегменты остаются зашифрованными; дескриптор содержит лишь непрозрачный key-set ID CDM, а не ключи музыки. Cache index/manifest — приватные данные приложения и могут содержать подписанные CDN-URL. Резервное копирование приложения отключено. Кэш не является экспортируемым MP3.

Выход из аккаунта удаляет сессию и новые записи `licensed_offline` (старые локальные оригиналы предыдущих версий сохраняются). Офлайн-записи привязаны к аккаунту и устройству, не переносятся как обычные файлы. Системный CDM может сохранять внутренние записи лицензий до собственного удаления/истечения; приложение не обещает отзывать лицензию на стороне сервера.

## Ограничения и статус

**Нативный DRM и выдача offline-лицензии ещё не проверены end-to-end на реальном Widevine-устройстве с вашим аккаунтом.** В AOSP-эмуляторе Widevine отсутствует. См. TESTING.md: проверены сборка, отказ без CDM, публичные метаданные проблемного трека и обычное локальное воспроизведение.

- Реальная выдача лицензии зависит от устройства, provisioning, аккаунта, региона, прав и серверной политики SoundCloud. Получение streaming-лицензии не гарантирует offline-лицензию.
- Для офлайн поддерживается конечный отдельный HLS media playlist. Master-only/live-плейлист, отсутствие PSSH, отказ сервера, истёкшая лицензия и неподдерживаемый CDM не обходятся.
- Срок лицензии может закончиться уже после скачивания. Тогда нужно повторно загрузить трек при наличии сети и разрешения сервиса. Автообновление лицензий не реализовано.
- Нельзя гарантировать отсутствие сервисной рекламы, доступ ко всем трекам, полный трек вместо разрешённого сервером превью или действие VPN.
- Обычный незащищённый поток не записывается в обход `downloadable=false`.
- Разрешение правообладателя и условия сервиса нужно проверить до распространения. Лицензия открытого кода не даёт прав на музыкальный контент. Приложение не аффилировано с SoundCloud.

## Сборка

JDK 21, Android SDK platform 35 / build-tools 35.0.0, Gradle wrapper 8.9 (AGP 8.7.3).

```bash
export JAVA_HOME=/path/to/jdk-21
export ANDROID_HOME=/path/to/android-sdk
export PATH="$JAVA_HOME/bin:$PATH"
./build-apk.sh
```

При отсутствии локального `build/manual/test.keystore` скрипт создаёт **новый** тестовый ключ. Сборка из этого архива не обновит старый APK без исходного приватного ключа, который в архив намеренно не включён. Для своих релизов настройте собственную безопасную подпись. Gradle скачивает зависимости из стандартных репозиториев.

```bash
mkdir -p build/tests
javac -d build/tests app/src/main/java/app/volna/direct/{AuthCapture,StreamPolicy}.java tests/*.java
java -cp build/tests AuthCaptureTest
java -cp build/tests StreamPolicyTest
```
