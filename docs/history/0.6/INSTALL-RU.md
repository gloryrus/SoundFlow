# SoundFlow 0.6 — установка и проверка

1. Установите APK **поверх Lab 0.5**, не удаляя старую Lab: подпись та же, аккаунт и загрузки сохраняются. Отдельная версия 0.4 не обновляется этим APK.
2. «Для вас → Моя волна → ☷»: переключатель «Играть знакомые треки» и баланс открытий/любимого. При выключении исключаются лайки и прослушивания, известные этой Волне. Вкладки больше не пересоздают сохранённую подборку.
3. Проверьте лайк и создание приватного плейлиста. Операция отправляется из приложения без страницы браузера. Успех показывается только после успешного ответа сервера. Реальный приём запросов вашим аккаунтом необходимо проверить на телефоне; 401/403 не удаляют сессию или скачанные файлы.
4. «Медиатека → Загрузки / Авто → Обновить список и повторить ошибки» — после обновления повторно проверяет прежние отказы с новой обработкой HLS. Готовые файлы не скачиваются снова. «Продолжить» соблюдает срок повторной попытки.
5. Если трек всё ещё не скачался: «Причины отказов → Скопировать отчёт». Отчёт содержит названия/ID треков и код причины, без токенов, cookie и адресов аудио. Его можно отправить для диагностики.
6. Закрытие медиауведомления останавливает и освобождает плеер. Если Android не позволяет смахнуть активное уведомление, используйте действие «Остановить». Простое сворачивание/закрытие окна приложения оставляет фоновое прослушивание.

Очередь, автосохранение новых добавлений, Wi-Fi/безлимитная сеть и исходные плейлисты сохраняются. Android может отложить фоновую проверку. Копия доступна и в исходном плейлисте, и в «Офлайн», без двойного расхода памяти.

Офлайн требует разрешённого автором оригинала или выданной SoundCloud офлайн-лицензии. Превью не превращаются в полный трек; блокировки и DRM не обходятся. Не обещается скачивание всех записей. Лицензия может истечь.

Сохраните уже выданный личный архив ключа Lab 0.5: он подходит и для дальнейших обновлений 0.6. Не публикуйте его. В публичном архиве исходников ключа нет.
