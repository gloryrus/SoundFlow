# SoundFlow 0.12 — установка и проверка

Установите APK поверх Lab0.5–0.11 без удаления приложения и очистки данных. Подпись и пакет прежние.

## Лайки и плейлисты
1. Нажмите лайк или создание/добавление в плейлист как обычно. Откроется видимое окно SoundCloud; операция выполняется один раз после загрузки сайта.
2. Если сервис выдал проверку, пройдите её в этом окне. После успешной проверки нажмите «Выполнить» для подтверждения повтора. Само прохождение проверки ещё не сохраняет лайк/плейлист.
3. При неизвестном результате сначала проверьте сайт. Не создавайте плейлист повторно, пока не убедились, что первого нет. Успех отображается только после ответа сервера.
4. Если на сайте другой аккаунт, запись остановится. Подключите нужный аккаунт. Пароль вводится только на официальной странице, а не в чате.
5. Нужен Android System WebView/совместимый системный Chrome. При недоступном компоненте приложение сообщает об этом; загрузки и сессия не удаляются. Аудио остаётся нативным.

## Офлайн
Четыре NO_OFFLINE_SOURCE из скриншота не объявлены исправленными. Публичная проверка нашла full HLS для прослушивания, но downloadable=false. Постоянная копия без разрешённого источника/лицензии не создаётся. Это не доказывает, что обычное онлайн-воспроизведение неполное. Не удаляйте готовые копии. «Повторить ошибки» полезно только после реального изменения доступности/прав, а не выдаёт их.

Проверка реального лайка/приватного плейлиста на вашем аккаунте всё ещё нужна; тесты не используют ваши данные и не могут обещать принятие запросов SoundCloud.
