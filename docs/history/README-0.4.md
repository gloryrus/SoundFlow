# Волна Direct 0.4.0 — плейлисты и персональная волна

Независимый экспериментальный Android-клиент SoundCloud. Android 8.0+, Java, AndroidX Media3 1.5.1. Не аффилирован с SoundCloud. Это не полный клон сервиса и не гарантия доступа ко всему каталогу.

## Установка

Ставить APK **поверх 0.3.0/0.2.1-loginfix без удаления приложения**. ApplicationId тот же: `com.farika.soundflow.loginfix`, versionCode 5, сертификат подписи сохранён. Удаление старой версии уничтожит сессию и локальные данные. Если Android сообщает о несовпадении подписей, не удаляйте старое приложение автоматически.

## 1. Лайки / HTTP 403

Вместо прежнего web PUT/DELETE используется нативный запрос из KittyTune:

- `POST https://api-mobile.soundcloud.com/likes/tracks/create`
- `POST https://api-mobile.soundcloud.com/likes/tracks/delete`
- JSON `likes[].target_urn = soundcloud:tracks:<id>`

Передаётся собственная сессия пользователя. `client_secret`, официальный client ID, официальный User-Agent и чужая идентичность устройства не используются. Для мобильного запроса нет query с токеном или client_id. Лайк меняется в интерфейсе **лишь после успешного ответа сервера**. Повторные нажатия во время запроса блокируются.

Формат запроса, авторизация и отказ 403 проверены на изолированном mock-сервере, **но успешная запись лайка с вашим реальным аккаунтом здесь не проверена**. Поэтому это не обещание, что любой серверный 403 устранён. Если остаётся отказ, приложение покажет отдельный диалог с `LIKE_MOBILE_403`; локальный фальшивый лайк и анонимная повторная попытка не выполняются. Переподключите аккаунт и проверьте лайк также на сайте SoundCloud.

## 2. Плейлист целиком

В «Медиатека → Плейлисты»:

- Долгое нажатие на плейлист → подтверждение загрузки целиком.
- Либо открыть плейлист → кнопка **↓** справа от «← Плейлисты».
- Прогресс и итог — в уведомлении. Загрузка последовательная, с отменой всей очереди.

Плейлист не переносится в отдельный безымянный офлайн-список: сохраняются его исходный ID, название, порядок и состав, включая недоступные позиции. Завершённые копии видны **и в исходном плейлисте, и в общем «Офлайн»**. Один трек в нескольких плейлистах хранится один раз, без двойного расхода памяти.

В плейлисте показывается `N / M на устройстве`, а у сохранённых треков — **↓**. Во время воспроизведения исходного `sc:<id>` автоматически выбирается его сохранённая копия. При отсутствии сети очередь исключает нескачанные треки. Все доступные копии остаются в общем офлайн-разделе.

Список плейлиста сохраняется локально. Когда сеть недоступна/запрос не проходит, открывается сохранённый снимок. При обычном открытии онлайн список обновляется с SoundCloud; для загрузки новых треков снова нажмите ↓. Это **не постоянная фоновая синхронизация**: новая музыка не скачивается без отдельного действия. Удаление трека из серверного списка не удаляет автоматически его общую копию, которая может использоваться другим плейлистом.

Если часть треков недоступна, не утверждается, что плейлист полностью скачан: итог содержит число несохранённых. Повторная загрузка пропускает готовые копии и повторяет недостающие. После завершения/отмены/убийства процесса Android готовые копии остаются; незавершённую очередь нужно запустить снова. Внутри одного трека возобновление частичного файла не обещается.

«Офлайн» — приватное хранилище приложения, а не экспорт в общую Android-папку MP3. Защищённые треки остаются зашифрованными. Срок офлайн-лицензии может закончиться после загрузки: тогда удалите старую копию через «Офлайн» и загрузите заново при наличии сети и разрешения сервера. Удаление общей копии убирает доступность офлайн во всех использующих её плейлистах.

## 3. Ваша волна

Вместо рекомендаций от единственного последнего лайка:

- До 6 разных seed-треков из последних 100 лайков и интересных прослушиваний на устройстве.
- Related-кандидаты напрямую SoundCloud; объединение и повторное ранжирование локально.
- Режимы **Микс / Открытия / Знакомое** с разным предпочтением знакомых треков.
- Учитываются реальное время звучания, достаточное прослушивание и быстрые пропуски. Перемотка не считается временем прослушивания. Превью и ошибки не обучают вкус.
- Дослушивание усиливает интерес, быстрый пропуск снижает. Недавним повторам и повторению одного исполнителя/загрузчика даётся штраф.
- Исключаются скрытые треки, известные превью и блокировки; дубликаты удаляются по SoundCloud ID.
- Под треком — краткая причина рекомендации. «Обновить волну» меняет источники в доступном наборе.
- Долгое нажатие на трек → **Не рекомендовать этот трек**. Это локальный фильтр, не удаление из серверного плейлиста и не снятие лайка.
- ⚙ → объяснение и сброс локальной истории. Лайки SoundCloud при сбросе не удаляются.

Это **собственная эвристика**, не модель и не данные Spotify/Яндекс Музыки. Качество «лучше оригинала» не доказано. Нет аудио-эмбеддингов, скрытого анализа BPM/настроения и доступа к чужим рекомендательным системам. Слабый/пустой профиль даёт более ограниченную ленту. При проблемах сети используются доступные сохранённые интересы с явной подписью.

История вкусов привязана к аккаунту, хранится в приватных SharedPreferences на устройстве (не более 1000 записей), не выгружается на сервер разработчика. Основные запросы к SoundCloud/его CDN всё равно видны самому сервису. Передача локального времени звучания серверу разработчика не реализована. Выход очищает текущую локальную историю и снимки плейлистов.

## 4. Hurt и 30-секундные превью

Для `christianreindl-music/hurt-feat-lloren` публичный ответ на проверке показал:

- `policy = SNIP`, `monetization_model = SUB_HIGH_TIER`;
- `duration = 30000`, `full_duration = 216085`;
- только 30-секундные варианты, `snipped = true`.

Это не прежняя ошибка «нет MP3/AAC». SoundCloud выдаёт превью в данном контексте доступа. В новой версии явно показывается **Превью 0:30 из 3:36** и объяснение ограничения. Свежие метаданные читаются с текущей сессией; если сервис выдаёт аккаунту полный поддерживаемый поток, используется он. Превью не сохраняется как полный трек и не предлагается в персональной волне.

**Полную версию Hurt без соответствующего доступа мы не разблокировали и не обещаем.** Вход в обычный аккаунт и VPN сами по себе не дают прав на полный подписочный трек. Нужны разрешение сервиса для аккаунта/региона и, для защищённой музыки, действительная лицензия. Нет подмены источника и обхода платного доступа.

## Архитектура / ограничения

Сохранены прямое воспроизведение Media3/Widevine, проверка лицензии, защищённый кэш, поиск, библиотека, очередь и медиакнопки из 0.3.0. Воспроизведение — нативное, без браузера. Вход оставлен через официальный сайт в Android System WebView с проверкой `/me`: это неофициальный веб-клиент, не зарегистрированное developer-приложение.

Сети: soundcloud.com, api-v2.soundcloud.com, api-mobile.soundcloud.com (только create/delete лайков), CDN SoundCloud и его сервер лицензий. Для стандартного provisioning CDM возможен доверенный Google endpoint. Нет собственного посредника, scnative.space, YouTube/Spotify-подмены или извлечения DRM-ключей. Собственная реклама не добавляется, отсутствие рекламы сервиса не гарантируется.

Офлайн доступен лишь для разрешённых оригиналов либо после выдачи постоянной лицензии. Геоограничения, тариф и отказы сервера не обходятся. Нативный DRM и реальные лицензии не тестировались в AOSP-эмуляторе без Widevine; см. TESTING.md. Подробнее о безопасности и архитектуре 0.3.0 — в `docs/README-0.3.0.md` (новые изменения выше имеют приоритет).

## Сборка и тесты

JDK21, SDK35/build-tools35.0.0, Gradle wrapper8.9 / AGP8.7.3:

```bash
export JAVA_HOME=/path/to/jdk-21
export ANDROID_HOME=/path/to/android-sdk
export PATH="$JAVA_HOME/bin:$PATH"
./build-apk.sh
```

Приватный ключ подписи не включён в исходники. Скрипт при отсутствии ключа создаёт новый тестовый ключ; такая сборка сама по себе не обновит старый APK с другим сертификатом. Для распространения настройте собственную безопасную подпись.

```bash
mkdir -p build/tests
javac -d build/tests app/src/main/java/app/volna/direct/{AuthCapture,StreamPolicy,RecommendationRanker}.java tests/*.java
java -cp build/tests AuthCaptureTest
java -cp build/tests StreamPolicyTest
java -cp build/tests RecommendationRankerTest
```

Соответствующие исходники, инструкции, тесты и лицензии приложены к APK. Комбинированная сборка GPL-3.0; Media3 Apache-2.0. Ссылки на адаптированный код KittyTune и отличия — в THIRD-PARTY-NOTICES.md. Лицензии открытого кода не дают прав на музыку или ограниченный сервисный доступ.
