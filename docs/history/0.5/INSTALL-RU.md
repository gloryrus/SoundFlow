# SoundFlow 0.5 — тестовая версия

1. Установите APK как отдельное приложение «SoundFlow». Версию 0.4 не удаляйте: она остаётся отдельно, её данные не изменяются.
2. Войдите в SoundCloud заново в Lab. Старый вход и кэш из 0.4 не переносятся.
3. Проверьте один лайк и создание одного приватного плейлиста. Откроется видимая официальная страница внутри приложения. Дождитесь загрузки сайта → «Выполнить» → подтвердите. Проигрывание остаётся нативным, веб-компонент используется только для аккаунта.
4. «Медиатека → Любимое → ↓ Всё любимое» или стрелка ↓ в плейлисте: можно скачать весь список и включить «Автоматически сохранять новые треки».
5. «Медиатека → Загрузки / Авто»: прогресс, продолжение очереди, повторная проверка, переключатели автозагрузки и сети. По умолчанию автозагрузка — только в безлимитной сети (обычно Wi-Fi). Android может отложить периодическую проверку; мгновенное скачивание новых лайков не гарантируется.
6. При 401: «Аккаунт → Обновить вход». При 403 проверьте видимую страницу: SoundCloud может требовать проверку или отказать в операции. Данные и загрузки из-за ошибки не удаляются. Если результат запроса неизвестен, сначала проверьте его на сайте — повторное создание может дать дубликат.

Готовые аудиокопии используются в исходном плейлисте и показываются в «Офлайн» без двойного расхода памяти. Очередь хранится между запусками. Ручную очередь после остановки процесса можно продолжить в разделе загрузок. Незавершённый файл может скачиваться сначала. Изменения состава списка не удаляют уже скачанные копии автоматически.

Важно: это экспериментальный способ работы с сайтом, не официальный OAuth-клиент. Приём лайков/плейлистов реальным аккаунтом нужно проверить на вашем телефоне. Успешные тесты с искусственными ответами не являются такой проверкой.

30-секундные превью не превращаются в полные треки. Для офлайна нужен разрешённый автором оригинал или лицензия SoundCloud. Если сервис отказал в праве/лицензии, запись остаётся нескачанной. Платный доступ, DRM и геоограничения не обходятся. Лицензия может истечь.

Отдельный архив signing-backup — личная резервная копия ключа новой Lab-сборки. Сохраните его в безопасном месте и не публикуйте: он нужен для будущих обновлений Lab, не содержит ваш аккаунт SoundCloud.
