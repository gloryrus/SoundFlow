# SoundFlow 1.0.0

- Имя приложения SoundFlow; applicationId и namespace com.farika.soundflow без debug-суффикса. Java main/test/androidTest перенесены в соответствующий пакет. Запросы внутри приложения используют новые action names.
- Стандартный Gradle debug signing без зависимости от отсутствующего приватного ключа прежней Flow. Для release — только переменные окружения, не пароли в коде.
- VS Code tasks: Debug APK (задача сборки по умолчанию), unit-тесты, release, clean. Wrapper для Windows/Linux/macOS включён. README описывает SDK/JDK, выходные APK и подпись.
- Полноразмерная adaptive launcher icon с собственным тёмным background, отдельным foreground и Android13+ monochrome; legacy PNG для density. Белая подложка, вызванная неадаптивной маленькой иконкой, больше не задаётся приложением. Конкретную маску выбирает launcher.
- При паузе сохраняется MediaStyle/MediaSession настоящий плеер, как раньше. При реальном onDestroy службы уведомление снимается; не публикуется отдельная обычная карточка «На паузе». Checkpoint остаётся для восстановления. После уничтожения процесса Android обещать живой плеер невозможно.
- Персональная волна получает отдельный persisted wave-флаг в checkpoint. Prefetch при5 оставшихся треках; следующая порция до30 в отдельном worker, без Activity. В конце ожидает результат, не переключается по кругу на начало. После сетевой ошибки/пустой выдачи повтор примерно через минуту, только при намерении воспроизведения. Смена очереди/аккаунта/закрытие игнорируют устаревшие результаты.
- Генератор использует next_href источников для продолжения, исключает текущую очередь и недавние треки, сохраняет ранжирование/фильтрацию/ограничения доступа. В памяти движущееся окно очереди, до10 предыдущих при подгрузке, история последних240. Это не обещание вечной уникальности. Новые страницы списка на главной появляются автоматически при прокрутке, окно UI до180 строк.
- Новые метаданные волны сохраняются отдельно на диске в account-scoped SQLite WaveCatalog, не накапливаются целиком в Library. Существующие записи пользовательской библиотеки не удаляются. При исчерпании свежих кандидатов допускается более старый трек вне текущей очереди, а не безусловная остановка после фиксированной выдачи.
- «Своё», эквалайзер, плейлисты, лайки, сохранение позиций и офлайн-механизмы предыдущей версии оставлены.

Новый пакет не получает sandbox старой Flow. Автоматический перенос аккаунта/лицензий/офлайн-записей между пакетами не реализован. Приватные ключи, SDK-пути и кеши не включены в публичные исходники.
